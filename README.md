## ✨ Features

* 🤖 Real Computer AI with **Stockfish**
* ♟️ Player vs Computer & Player vs Player
* ⏱️ Chess Timer
* ↩️ Undo Move
* 📜 Move History
* ⚔️ Captured Pieces
* 🔊 Chess Sound Effects
* 🎨 Multiple Board Themes
* ✨ Smooth Piece Animations
* 📱 Fully Responsive Design
* ♟️ Check, Checkmate & Draw Detection

## 🛠️ Built With

* **React.js**
* **Vite**
* **Tailwind CSS**
* **JavaScript**
* **chess.js**
* **Stockfish**

## 🚀 Run Locally

```bash
npm install
npm run dev
```
